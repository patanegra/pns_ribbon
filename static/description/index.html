PNS Ribbon

Never confuse production with staging again.

A lightweight, version-proof environment indicator for Odoo 13–19+

Displays a configurable diagonal ribbon in the corner of every backend page to clearly identify non-production instances (TEST, DEV, STAGING, etc.).

Unlike other ribbon modules, PNS Ribbon is immune to Odoo frontend changes between versions — it injects vanilla JS/CSS directly into the <head>, bypassing the asset bundler entirely.

Features

  • 🎨 Color picker + opacity slider — native picker with pasteable rgba(...) field
  • 👁️ Live preview — see the final look before saving
  • 📋 History grid — last 20 color combinations, one click to reuse
  • ⚙️ On/off switch — hide without uninstalling
  • 🎭 Shadow toggle — flat or shadowed look
  • 📐 Variables — {dbname}, {user}, {company}
  • 🔄 Multi-line text — one line per row
  • 🛡️ Bundler-proof — no odoo.define, no OWL, no jQuery

Configuration

Activate debug mode, then open Settings → Technical → Ribbon (administrators only) to configure text, colors, opacity and preview the result in real time.

Text Variables

VariableReplaced with
{dbname}Database / instance name
{user}Current user's display name
{company}Current company's name

Architecture

The ribbon is version-agnostic by design: it inherits web.layout and injects a <script> + <link> directly into the <head>, bypassing the Odoo asset bundler. The only version-specific piece is the color picker widget in the configuration form (OWL1 for Odoo 13–14, OWL2 for Odoo 15–19+).
